Controles rápidos Fechar

Mouse

No PC, ESC libera o ponteiro da área do jogo.

Toque (celular)

Deslize na tela como em um touchpad para mover o cursor dentro do jogo.

Navegação no jogo

Use as setas e Enter como no teclado clássico. Os botões flutuantes repetem essas teclas.
